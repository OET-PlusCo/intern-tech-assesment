# AI Developer Assessment

Welcome to the AI Developer technical assessment!

## 📋 Overview

This assessment evaluates your ability to debug and optimize production machine learning code. You'll be reviewing a FastAPI service that serves a customer churn prediction model.

## 📁 Files for Candidates

- **`CANDIDATE_INSTRUCTIONS.md`** - Read this for detailed instructions
- **`buggy_model_api.py`** - The code you'll be debugging
- **`requirements.txt`** - Python dependencies (for reference)

## 🚀 Getting Started

1. Read `CANDIDATE_INSTRUCTIONS.md` for the full context
2. Review `buggy_model_api.py`
3. Your interviewer will provide specific instructions during the session

## ⏱️ Time

This is a live exercise conducted during your interview. Your interviewer will let you know how much time you have.

## 💡 Tips

- Think aloud so we understand your reasoning
- Ask clarifying questions if anything is unclear
- Focus on identifying issues and explaining their impact
- It's okay to say "I'm not sure" - we value transparency!

Good luck! 🎯
