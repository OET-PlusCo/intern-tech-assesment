# AI Developer Interview - Debugging Exercise

## Context

You're joining a team that has deployed a FastAPI service for predicting customer churn. The service worked in development, but is now experiencing issues in production.

## Your Task

**Time: 15 minutes**

Review the file `buggy_model_api.py` and:
1. **Find as many bugs as you can**
2. **Explain what each bug is and its impact**
3. **Describe how you would fix it**

## Guidelines

- **Think aloud**: Explain your reasoning as you debug
- **Ask questions**: If requirements are unclear, ask!
- **Prioritize**: Focus on the most critical issues first
- **Be honest**: It's okay to say "I'm not sure" or "I'd need to research this"

## What We're Looking For

We want to see:
- ✅ Your debugging process and systematic thinking
- ✅ How you prioritize issues
- ✅ Your understanding of production ML systems
- ✅ Your communication style
- ✅ How you handle ambiguity

## The Code

The file `buggy_model_api.py` contains a FastAPI application that:
- Loads a pre-trained churn prediction model
- Provides endpoints for single and batch predictions
- Should be production-ready (but it's not!)

## Tips

- You don't need to fix all bugs - we want to see your approach
- Consider both immediate errors and subtle production issues
- Think about data quality, ML-specific concerns, and API best practices

**Good luck! Feel free to ask any questions before we start.**
