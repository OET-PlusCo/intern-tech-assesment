## What the page contains

- A hero section: a decorative movie-poster banner, then the heading
  **"Find Movies You'll Love Without the Hassle"** with the word *Movies*
  in the purple accent colour.
- A search input with a magnifier icon and the placeholder
  "Search through 300+ movies online".
- A "Search" section heading.
- A responsive grid of movie cards (4 across on desktop). Each card shows the
  poster, the title, and a star rating.
